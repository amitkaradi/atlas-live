# QPM – Quantum Price Model

מודל מתמטי שמתאר את מחיר המניה העתידי כמצב קוונטי, ומפיק ממנו התפלגות תחזית, תוחלת, אחוזונים, VaR ומחירי אופציות.
המימוש: [`qpm.py`](qpm.py). תרחישים וגרפים: [`demo.py`](demo.py).

> מכניקת הקוונטים משמשת כאן כשפה מתמטית לאי־ודאות, לא כפיזיקה של השוק. ħ, "מסה" ו"אנרגיה" הם כלי מידול. זה לא ייעוץ השקעות.

---

## 1. משתנה המצב ומרחב הילברט

```
x = ln(S / S₀)                        תשואה לוגריתמית ביחס למחיר של היום
x ∈ [−L, L],  רשת של N נקודות,  |x_i⟩ מצבי בסיס ("מיקום")
```

המצב הוא **ספינור** עם שני רכיבים, קיוביט של סנטימנט (שורי/דובי) כפול חבילת גלים על רשת המחירים:

```
|Ψ(t)⟩ = |↑⟩ ⊗ |ψ_bull(t)⟩  +  |↓⟩ ⊗ |ψ_bear(t)⟩          Ψ ∈ ℂ² ⊗ L²(x)

p(x, t) = |ψ_bull(x,t)|² + |ψ_bear(x,t)|²                   כלל בורן: התפלגות המחיר
P(bull, t) = ∫ |ψ_bull|² dx
```

## 2. מצב התחלתי: חבילת גלים עם מומנטום

```
ψ_s(x, 0) = √p_s · (2πσ₀²)^(−1/4) · exp(−x² / 4σ₀²) · exp(i k₀ x)

p_↑ = p_bull ,  p_↓ = 1 − p_bull
```

| פרמטר | משמעות | כיול |
|---|---|---|
| σ₀ | אי־ודאות מיידית (רוחב החבילה) | מרווח bid-ask / תנודתיות תוך־יומית |
| k₀ | מומנטום: שיפוע הפאזה | k₀ = v / 2σ²,  v = מגמה שנתית מ־n הימים האחרונים (`momentum_from_returns`) |
| p_bull | הסתברות התחלתית לרגשי שוק שוריים | סקרי סנטימנט, put/call ratio, NLP על חדשות |

**עיקרון אי־ודאות שוקי.** מחיר ומגמה הם אופרטורים לא מתחלפים, [x̂, k̂] = i, ולכן

```
Δx · Δk ≥ 1/2
```

ככל שיודעים בדיוק רב יותר איפה המניה (σ₀ קטן), פחות יודעים לאן היא הולכת. (`QuantumPriceModel.uncertainty()`)

## 3. ההמילטוניאן

```
Ĥ  =  −σ² ∂²/∂x²   +   V(x)·𝟙   +   g·σ_z·x̂   +   Ω·σ_x
       ─────────       ─────────      ──────────     ────────
       קינטי:           כוחות השוק    צימוד          תדירות היפוך
       "מסה" m = 1/σ²                 סנטימנט↔מחיר   סנטימנט
```

- מניה עם תנודתיות נמוכה היא "כבדה" ומתפזרת לאט.
- σ_z ⊗ x̂: במצב שורי האנרגיה יורדת כשהמחיר עולה (המחיר נמשך למעלה), ובמצב דובי להפך.
- σ_x: מעבר בין שורי לדובי (תנודות ראבי בסנטימנט).

### 3.1 הפוטנציאל V(x)

```
V(x) = λ (x − x_f)²                                  חזרה לממוצע לשווי הפונדמנטלי x_f
     + Σ_j h_j · exp(−(x − x_j)² / 2w_j²)            רמות תמיכה/התנגדות (h_j>0 דוחה, h_j<0 מושך)
     + a x⁴ − b x²                                   בור כפול: שני משטרים לפני דוחות, מינימום ב ±√(b/2a)
     − D · exp(−(x − x_f)² / 2w²)                    "מגנט": בור מושך סביב המחיר הנוכחי
```

**סקאלת אנרגיה.** היחידה הטבעית היא 1/T. מאפיין בפוטנציאל משפיע באופק T רק אם V·T = O(1).
לאופק של 30 יום (T ≈ 0.12 שנה): מחסומים h ≈ 10–50, חזרה לממוצע λ ≈ 500–2000.

**תוצאה לא טריוויאלית:** המצב הקשור של בור מושך צר הוא ψ ∝ exp(−κ|x|). כלומר, "מגנט" במחיר הנוכחי מייצר **התפלגות לפלס** עם זנבות עבים, בלי להוסיף אותם ידנית. זה מה שמנצח את הגאוסיאן בתרחיש G.

## 4. משוואת התנועה: בין בלאק־שולס לשרדינגר

```
∂Ψ/∂t = − z · Ĥ Ψ ,       z = (1 − θ) + iθ ,    θ ∈ [0, 1]
```

| θ | משמעות |
|---|---|
| 0 | זמן מדומה: משוואת חום. בלי פוטנציאל זה **בדיוק** בלאק־שולס, p(x,T) = N(μT, σ²T + σ₀²). עם פוטנציאל: משקל פיינמן־קאץ exp(−∫V dt). |
| 1 | שרדינגר אוניטרי: התאבכות, תנועה בליסטית, המומנטום k₀ נשמר. |
| בין | ערבוב. ב־θ=0 הפאזה k₀ לא מזיזה את ההתפלגות; ב־θ=1 היא מזיזה אותה במהירות v = 2σ²k₀. לכן **θ = מידת ההתמדה של המומנטום**. |

הסחף μ (ריבית/פרמיית סיכון) מיושם כאופרטור הזזה exp(−i k μ t), תקף לכל θ.

**שונות אפקטיבית.** לחבילה חופשית (σ₀→0) מתקבל Var[x_T] = f(θ)·σ²T עם

```
f(θ) = (1 − θ) + θ² / (1 − θ)          f(0) = f(½) = 1 ,  f → ∞ כש־θ → 1
```

לכן מכיילים σ_model = σ_market / √f(θ), כך ש־θ שולט בצורת ההתפלגות (זנבות, התאבכות, התמדה) ולא בסקאלה שלה.

## 5. מדידה: עסקה כקריסה

עסקה "מודדת" את המחיר. דוגמים x_obs ~ p(x), ומקרינים:

```
ψ_s(x) → ψ_s(x) · exp(−(x − x_obs)² / 4σ_post²)  /  norm
```

ואז ממשיכים להתפתח. מסלול מחירים = רצף של {התפתחות → מדידה → קריסה}. (`measure()`, תרחיש F)

## 6. דה־קוהרנטיות: זרם מידע ונזילות

מצב מעורב מתואר במטריצת צפיפות ρ (ממד 2N × 2N) ומשוואת לינדבלד עם אופרטור מדידה רציפה L = x̂:

```
dρ/dt = −z[Ĥ, ρ]_z  −  (γ/2) [x̂, [x̂, ρ]]
⟹  ρ(x, x') → ρ(x, x') · exp(−γ (x − x')² t / 2)
```

האיברים הלא־אלכסוניים (קוהרנטיות בין מחירים שונים) דועכים בקצב γ(Δx)². הקוהרנטיות היא מה שמייצר התאבכות, ולכן γ גדול הורג את פסי ההתאבכות ומחזיר את ההתפלגות לקלאסית. השערה הניתנת לבדיקה: γ ∝ נפח מסחר / ADV. מניה נזילה היא קלאסית, מניה דלילה שומרת "זיכרון קוונטי". (תרחיש D)

## 7. כמה מניות: שזירה

עבור n מניות המצב חי ב־⊗ᵢ L²(xᵢ) ⊗ (ℂ²)^⊗n. צימוד ספק–לקוח: Ĥ_AB = J · x̂_A ⊗ x̂_B. מצב שזור כמו
α|↑_A↑_B⟩ + β|↓_A↓_B⟩ מתאר קורלציית סנטימנט שעשירה ממתאם קלאסי. מבחן CHSH על נתוני תשואות נותן קריטריון כמותי. (לא ממומש בקוד, הממד גדל אקספוננציאלית. ל־2–3 מניות אפשר להרחיב את `_apply_U`.)

## 8. פתרון נומרי

Split-step Fourier (Strang) בצעד dt:

```
Ψ ← e^{−zĤ_pot dt/2} · F⁻¹ e^{−z σ² k² dt − i k μ dt} F · e^{−zĤ_pot dt/2} Ψ
```

כאשר Ĥ_pot = V(x)𝟙 + b(x)σ_z + cσ_x נפתר אנליטית בכל נקודת רשת:

```
exp(−zt(bσ_z + cσ_x)) = cosh(zt·w)·𝟙 − sinh(zt·w)/w · (bσ_z + cσ_x),    w = √(b² + c²)
```

ב־θ<1 הנורמה לא נשמרת ומנרמלים מחדש כל צעד (זה משקל פיינמן־קאץ). N = 512 נקודות, 200 צעדים, פחות משנייה למריץ.

## 9. פלט התחזית

מ־p(x, T) מחשבים (`forecast()`):

```
E[S_T] = S₀ ∫ eˣ p(x) dx                  חציון, אחוזונים, P(S_T > S₀)
VaR_α = S₀ (1 − exp(q_α))                  skew, kurtosis
C(K) = e^{−rT} ∫ max(S₀eˣ − K, 0) p(x) dx  אופציות, ⟨Ψ| max(Ŝ−K,0) |Ψ⟩
P(bull, T)                                 סנטימנט חזוי
```

## 10. כיול

`calibrate(base, T, free, objective)` ממזער פונקציית מטרה על תת־קבוצה של פרמטרים (Nelder–Mead עם אילוצי תיבה):

1. **לשוק האופציות:** objective = KL( q_RN ‖ p_model ), כאשר q_RN היא ההתפלגות הניטרלית לסיכון מ־Breeden–Litzenberger. המודל מעוגן במחירים אמיתיים.
2. **היסטורי:** objective = −Σ log p(x_realised). תרחיש G מראה על נתונים עם זנבות עבים (t עם 3 דרגות חופש) שיפור של כ־+190 ב־log-likelihood מחוץ למדגם על 2,000 תצפיות לעומת גאוסיאן.

## 11. מה המודל טוען ומה לא

- **טוען:** שפה אחת שמכילה את בלאק־שולס כמקרה פרטי (θ=0, V=0), ומוסיפה: זנבות עבים מבור מושך, דו־שיאיות מבור כפול, התמדת מומנטום דרך θ, רמות טכניות כמחסומים, סנטימנט כקיוביט, ונזילות כדה־קוהרנטיות.
- **לא טוען:** שאפשר לתזמן את השוק. ב־θ=0 וללא מידע עודף התחזית זהה לבלאק־שולס. היתרון, אם קיים, הוא בצורת ההתפלגות.
- **סיכון:** הרבה פרמטרים חופשיים. חובה לבדוק מחוץ למדגם מול GARCH ו־Heston לפני כל שימוש.

```python
from qpm import QPMParams, Potential, QuantumPriceModel, effective_variance_factor
import numpy as np

theta = 0.5
p = QPMParams(
    sigma=0.30 / np.sqrt(effective_variance_factor(theta)),
    mu=0.04, sigma0=0.02, k0=4.0, theta=theta, g=100, omega=5, p_bull=0.6,
    potential=Potential(lam=1200, x_f=np.log(1.08), levels=[(np.log(0.9), 30, 0.015)]),
)
m = QuantumPriceModel(p, S0=100).evolve(T=30/252)
print(m.forecast(r=0.04, strikes=[100, 110]))
```
